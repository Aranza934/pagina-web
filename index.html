SLA

Los SLA (Service Level Agreement) son acuerdos de nivel de servicio entre un proveedor y un cliente.

  • Definición de servicios
  • Tiempos de respuesta
  • Disponibilidad del sistema
  • Soporte técnico

ITIL v3

ITIL v3 es un conjunto de buenas prácticas para la gestión de servicios de tecnologías de la información.

Ayuda a mejorar la calidad de los servicios, reducir costos y optimizar procesos.

Normas ISO

ISO 14001

Norma enfocada en la gestión ambiental y sostenibilidad.

ISO 31000

Norma utilizada para la gestión y análisis de riesgos.

ISO/IEC 20000

Norma internacional para la gestión de servicios TI.

Bugzilla

Bugzilla es una herramienta utilizada para el seguimiento de errores y gestión de incidencias.

  • Registro de errores
  • Seguimiento de incidencias
  • Control de tareas
  • Gestión de proyectos

Planes Operativos y Contingenciales

Planes Operativos

Documentos que describen las actividades diarias de un sistema o servicio.

Planes Contingenciales

Estrategias diseñadas para responder a fallas y emergencias.

Monitoreo de Sistemas

El monitoreo permite supervisar servidores, redes y aplicaciones.

Ayuda a detectar fallas rápidamente y garantizar la continuidad del servicio.
